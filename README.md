# ChessMind Arena

An open-source LLM-powered chess arena exploring how retrieval,
reasoning, and different open-source LLMs can improve chess
decision-making.

## Project Status

🚧 Work in Progress

## Current Features

- Chess game management
- Legal move validation
- FEN generation
- Move state management
- FastAPI backend
- python-chess integration

## Planned Features

- Open-source LLM chess players
- Multi-model support
- Chess-specific RAG
- Candidate move generation
- LLM reasoning
- Stockfish-based evaluation
- Model comparison and leaderboard
- Web frontend

## Architecture

The project is being developed incrementally, starting with the
core chess backend and gradually adding LLMs, retrieval,
evaluation, and the frontend.
